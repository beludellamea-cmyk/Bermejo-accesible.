Preparando…

La primera vez se descargan las herramientas de lectura. Tu archivo no se envía a ningún servidor.

Qué puede hacer esta web y qué no
  • Lee texto impreso de fotos y PDF escaneados. La letra manuscrita, las tablas, las columnas y las fórmulas suelen salir con errores: por eso siempre podés corregir el texto.
  • Lee hasta 40 páginas por PDF. Los PDF con contraseña no se pueden abrir.
  • No lee formatos de foto HEIC en la mayoría de los navegadores. Guardá la foto como JPG o PNG.
  • Los títulos y las partes se detectan de forma automática y pueden no coincidir con el original.
  • La voz depende de las voces instaladas en tu dispositivo.
  • «Texto con imágenes» usa una colección chica de dibujos propios. Si no hay uno que corresponda, no se muestra imagen.
  • «Texto con pictogramas» necesita internet y consulta el catálogo de ARASAAC.

Lectura en voz alta

Tu navegador no tiene lectura en voz alta. Probá con Chrome, Edge, Safari o Firefox actualizados. Si usás un lector de pantalla, podés leer el texto con él.

La lectura empieza solo cuando tocás «Escuchar». Se lee un bloque por vez y el bloque que se está leyendo queda marcado con la palabra «Leyendo».

Vista por partes

Cada título del texto empieza una parte nueva. Si el texto no tiene títulos, cada párrafo es una parte. Usá el índice para saltar y marcá las partes que ya leíste.

Texto con imágenes

Buscamos en cada párrafo palabras de una colección de dibujos simples (agua, sol, lluvia, río, planta, escuela y otras). Si una idea no tiene un dibujo que le corresponda, se muestra solo el texto.

Texto con pictogramas

Antes de buscar: para encontrar los pictogramas se envían a ARASAAC hasta 4 palabras sueltas por párrafo (no el texto completo ni tu archivo). Necesitás conexión a internet.

Elegimos palabras de cada párrafo de forma automática. Solo mostramos un pictograma cuando ARASAAC tiene uno con esa misma palabra. Si no hay, queda solo el texto.
